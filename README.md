# Automotive Ethernet Rev1

Altium Designer source files for the Automotive Ethernet Rev1 project.

Open `Automotive_Ethernet_Rev1.PrjPcb` in Altium Designer. Keep the `Libraries/`
directory alongside the project so the relative library paths resolve.

| File | Purpose |
| --- | --- |
| `Automotive_Ethernet_Rev1.PrjPcb` | Altium PCB project |
| `01_PHY_Standard.SchDoc` | Standard Ethernet PHY schematic |
| `02_PHY_Automotive.SchDoc` | Automotive Ethernet PHY schematic |
| `03_Clock_Control.SchDoc` | Clock and control schematic |
| `04_Power.SchDoc` | Power schematic |
| `05_Connectors_Protection.SchDoc` | Connectors and protection schematic |
| `PCB1.PcbDoc` | PCB layout |
| `Libraries/ProjectSymbols.SchLib` | Local schematic symbol library |
| `Libraries/ProjectFootprints.PcbLib` | Local PCB footprint library |

The repository contains the current project source and local libraries.
Local history, backups, logs, generated previews, vendor PDFs, and the separate
reference gateway design are excluded by `.gitignore`.
